# Icônes Igitoro Live

## Fichiers nécessaires :
- icon-192.png (192×192 px)
- icon-512.png (512×512 px)
- icon-maskable-512.png (512×512 px, logo centré avec 40% de marge)
- icon-180.png (180×180 px, pour iOS)
- favicon-32.png (32×32 px, pour navigateur)

## Design recommandé :
- Fond : vert foncé #1A3C2A
- Logo : lettre "I" ou symbole ⛽ en blanc #FFFFFF ou doré #C9A84C
- Format : PNG avec transparence (sauf maskable qui doit avoir un fond plein)

## Comment les créer (gratuit) :
1. Va sur https://favicon.io/favicon-generator/
2. Texte : "I"
3. Couleur du texte : #FFFFFF
4. Couleur du fond : #1A3C2A
5. Police : Plus Jakarta Sans
6. Télécharge le pack complet
7. Renomme les fichiers selon la liste ci-dessus
